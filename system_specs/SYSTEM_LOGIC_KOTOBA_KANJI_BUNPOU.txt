================================================================================
1. ARSITEKTUR UMUM & ALUR DATA KNOWLEDGE ENGINE
================================================================================
Nihongo Quest memisahkan konten pembelajaran ke dalam 3 entitas Core Knowledge:
1. Kotoba (Vocabulary) : Mengukur kelancaran leksikal dan kemampuan membaca kata.
2. Kanji (Character)   : Mengukur pengenalan bentuk visual, radikal, onyomi/kunyomi,
                         serta memori kinetik (goresan tulisan kuas).
3. Bunpou (Grammar)    : Mengukur sintaksis kalimat, rumus sambungan part of speech,
                         nuansa kontekstual, dan pembentukan kalimat aktif/pasif.

Prinsip Hubungan Data:
- Stage HANYA menyimpan relasi ID (contoh: kotobaIds: ["kotoba_0001"], kanjiIds: [...]).
- Materi tidak tahu ia berada di stage mana (independen kurikulum).
- User progress (Mastery 4D, XP, SRS, Streak) disimpan terpisah di user state / Supabase.
- Setiap aktivitas otomatis mengirim event ke 'user_activity' di database Supabase.

2. MODUL 1: KOTOBA (VOCABULARY / KOSAKATA)

2.1. SYSTEM LOGIC & SIKLUS STATE
---------------------------------
Alur kerja modul Kotoba (KotobaModule.tsx):
1. Resolusi ID Stage:
   - Komponen menerima props 'kotobaIds: string[]' dari stage yang aktif.
   - Mengambil data penuh dari KOTOBA_DATABASE (kotoba.json).
   - Jika stage tidak mendefinisikan ID khusus, modul menggunakan fallback 15 kata acak.
2. Tiga Mode Pembelajaran Utama:
   a. Mode Library (Daftar Lengkap):
      - Menampilkan seluruh kosakata dalam stage dalam bentuk grid kartu.
      - Klik kartu akan membuka 'KotobaDetailModal' yang menampilkan detail kamus.
   b. Mode Flashcard:
      - Mengambil pool 15 kata secara acak (shuffled).
      - Menampilkan kartu dua sisi (flip card). Sisi depan: Kanji/Kana + Audio.
        Sisi belakang: Romaji, Arti Indonesia, Arti Inggris, Definisi Jepang,
        Collocation (kolokasi umum), dan Contoh Kalimat.
      - Menyediakan navigasi Previous / Next dengan animasi slide.
   c. Mode Quiz & Exam:
      - Mengambil 25 soal acak untuk 'Practice Quiz' atau seluruh soal untuk 'Mastery Exam'.
      - Setiap soal digenerate secara dinamis:
        * Tipe 1: Arti Indonesia ditampilkan -> pilih kata Jepang yang tepat.
        * Tipe 2: Kata Jepang ditampilkan -> pilih arti Indonesia yang tepat.
        * Opsi distraktor diambil secara acak dari database kosakata selevel.
3. Fitur Handwriting (KotobaWritingPractice.tsx):
   - Jika user memilih latihan menulis kata, kata diurai menjadi array karakter tunggal:
     Array.from(kotoba.word) -> ['勉', '強'].
   - Setiap karakter dimuat ke kanji writing canvas satu per satu secara berurutan.
   - Setelah semua karakter selesai ditulis benar, efek fanfare berbunyi dan audio
     pelafalan kata otomatis diputar.

2.4. LOGIKA PERHITUNGAN REWARD & MASTERY
------------------------------------------
- Base EXP per flashcard flip : 5 EXP (maksimal 1x per kata per sesi).
- Base EXP per kuis benar      : 15 EXP.
- Bonus Atribut INT (PlayerStats.int):
  expGained = baseExp * (1 + (playerInt * 0.005))  [Bonus +0,5% EXP per poin INT; kode: utils/rewards.ts calculateQuizReward].
- Gold didapat                 : 10 Gold per jawaban benar kuis.
- Perekaman Aktivitas          : sendScoreEvent('quiz_answer', kotoba.id, isCorrect)
  yang otomatis menulis ke tabel Supabase 'user_activity'.
- Mastery State                : LEARNING -> COMPLETED -> MASTERED -> PERFECTED. Aturan (kode: utils/mastery.ts recordItemAttempt):
    COMPLETED = akurasi percobaan >= 70% atau masteryPercentage >= 60;
    MASTERED  = masteryPercentage >= 80 DAN attemptsCount >= 2;
    PERFECTED = masteryPercentage >= 98 DAN attemptsCount >= 3 DAN consecutivePerfects >= 2 DAN interval SRS >= 4 hari.
  Interaksi ringan (flip flashcard / latihan tanpa nilai, recordItemInteraction) dibatasi maks 70% dan tidak bisa mencapai MASTERED/PERFECTED.
- SRS                          : tangga interval tetap [1,2,4,7,14,30] hari (tanpa ease factor).
    Jawaban sempurna naik satu anak tangga; salah < 60% reset ke 1 hari; salah sebagian (60-99%) turun satu anak tangga.

3.1. SYSTEM LOGIC & SIKLUS STATE
---------------------------------
Alur kerja modul Kanji (KanjiModule.tsx & KanjiWritingCanvas.tsx):
1. Pengelompokan Data:
   - Modul menerima 'kanjiIds: string[]' dari stage aktif.
   - Mengambil entitas kanji dari KANJI_DATABASE dan daftar soal dari bank
     kuis mandiri (kanji_questions.json).
2. Dua Tab Operasi:
   a. Tab Daftar Kanji (List):
      - Menampilkan grid kartu kanji dengan karakter besar, arti singkat, dan radikal.
      - Klik kartu membuka tampilan Kanji Detail & Writing Studio.
   b. Tab Kuis Kanji:
      - Menjalankan kuis multiple choice 7 soal per set.
      - Soal mencakup: bacaan onyomi/kunyomi dalam kalimat, hitungan coretan (stroke count),
        serta identifikasi radikal utama.
3. Engine Kaligrafi & Menulis (HanziWriter Integration):
   - Sistem tidak menyimpan SVG raksasa di database utama, melainkan memanggil:
     * Cache internal memori (strokeDataCache).
     * Kamus embedded Kana untuk karakter Hiragana/Katakana (kanaStrokeDict.ts).
     * CDN resmi Hanzi-Writer Japan (hanzi-writer-data-jp) dengan format SVG koordinat.
   - Validasi Goresan Real-Time:
     * Pointer down/move/up di-capture pada canvas.
     * Mengukur arah goresan (angle), titik awal (start point), dan panjang coretan.
     * Toleransi akurasi disetel ke 0.80 (80% kemiripan).
     * Jika benar: coretan terisi warna hitam pekat (tinta kaligrafi sumi-e) dan
       muncul efek partikel tinta emas.
     * Jika salah: goresan berkedip merah dan bertambah pada 'mistakeCount'.

3.4. LOGIKA ENGINE MENULIS (STROKE MEMORY & CALIBRATED PRECISION)
-----------------------------------------------------------------
- Kalibrasi Toleransi Presisi : leniency = 0.95 (menolak goresan yang terlalu pendek
  atau keluar jalur; mewajibkan proporsi garis panjang vs pendek ditarik utuh).
- Validasi Arah Wajib         : acceptBackwardsStrokes = false (arah coretan harus
  sesuai kaidah baku, misal kiri-ke-kanan, atas-ke-bawah).
- Progressive Stroke Memory   :
  * Sistem melacak nomor coretan yang sedang aktif (currentStrokeIndex).
  * Coretan yang sudah berhasil (misal goresan 1〜3) tetap tersimpan di canvas.
  * Tombol 'Animasi' otomatis mendeteksi progres dan menganimasikan HANYA goresan
    yang belum selesai (misal goresan 4〜7).
  * Setelah animasi selesai, kuis langsung dilanjutkan pada goresan ke-4
    (quizStartStrokeNum: 3) tanpa mereset atau memaksa user mengulang dari goresan 1.
  * Tombol 'Ulangi' (RotateCcw) adalah satu-satunya aksi yang mereset canvas kembali ke goresan 1.
- Indikator Visual Progres    : Menampilkan badge "Goresan X/Y" secara real-time.
- Kecepatan Animasi Stroke    : 1.2x speed default.
- Warna Tinta                 : Solid Charcoal Brown / Dark (#57382A / #d4af37).
- Kalkulasi EXP Menulis       :
  Exp = Math.max(10, 100 - (totalMistakes * 10))
  Jika 0 salah -> Nilai 100% -> Sempurna (Perfect Stroke) -> Bonus Gold +50.
- Perekaman Event             : sendScoreEvent('kanji_write', kanji.id, totalMistakes === 0).

4.1. SYSTEM LOGIC & SIKLUS STATE
---------------------------------
Alur kerja modul Tata Bahasa (BunpouModule.tsx):
1. Resolusi Materi Stage:
   - Mengambil daftar pola tata bahasa untuk stage aktif dari 'bunpouIds: string[]'.
   - Mengambil data dari BUNPOU_DATABASE (bunpou.json) yang sudah decoupled.
   - Mengambil pohon cabang sub-rumus dari 'bunpouSubKnowledge.ts' dan metadata
     perbandingan fungsi dari 'bunpouMetadata.ts'.
2. Tampilan Dua Mode:
   a. Mode Materi Mandiri (Materi Tab):
      - Navigasi antar poin tata bahasa yang ada di stage (contoh: Pola 1, 2, 3).
      - Menampilkan formula interaktif, sub-rumus per kategori kelas kata,
        nuansa pemakaian, dan perbandingan dengan tata bahasa mirip.
   b. Mode Mixed Grammar Challenge:
      - Menarik 7 soal acak dari seluruh tata bahasa dalam minggu/bab tersebut.
      - Berfungsi sebagai mini-boss checkpoint sebelum membuka stage boss.
3. Kuis Penguasaan Pola Kalimat (QuizEngine):
   - 7 soal per tata bahasa dengan opsi distraktor terklasifikasi (errorTypeMap):
     * Distraktor konjugasi kata kerja (te-form, nai-form, passive vs causative).
     * Distraktor partikel (ni vs de vs wo).
     * Distraktor nuansa (keinginan langsung vs perkiraan orang lain).
4. Star Sentence Quiz (StarSentenceQuiz.tsx):
   - Kuis susun kalimat khas JLPT (Soal Tanda Bintang ★).
   - User menyusun 4 kata acak ke dalam 4 slot kalimat.
   - Jawaban dinilai berdasarkan kata yang jatuh tepat di posisi bintang (slot ke-3).

4.4. LOGIKA KUIS, HINT SKILL (MP), & 4D TRUE MASTERY
------------------------------------------------------
1. Logika MP 50/50 Hint:
   - Memeriksa MP pemain: PlayerStats.mp >= 15.
   - Jika cukup: potong 15 MP, sembunyikan 2 indeks jawaban salah, putar efek 'coin'.
   - Jika tidak cukup: tampilkan dialog peringatan "MP tidak mencukupi!".
2. Sistem Penilaian 4D True Mastery (TrueMasteryBreakdown):
   - Knowledge   (20%): Pemahaman teori, membaca sub-rumus & tabel koneksi kata.
   - Recognition (25%): Akurasi memilih pola yang benar pada kuis multiple-choice.
   - Application (35%): Kemampuan mengenali pola ini dalam teks Dokkai / Boss Battle.
   - Retention   (20%): Daya ingat jangka panjang yang diuji melalui interval SRS.
   -> True Mastery Score = (Knowledge*0.2) + (Recognition*0.25) + (App*0.35) + (Ret*0.20).
      (kode: utils/mastery.ts calculateItemTrueMastery; dipakai untuk antrean Recall & label status)
   -> Catatan: ada metrik TERPISAH `masteryPercentage` per item (recordItemAttempt) dengan 5 faktor:
      akurasi terbaik terdecay 20%, akurasi terkini 25%, streak retensi 20%, kesegaran SRS 15%, aplikasi kontekstual 20%
      (bila belum ada data kontekstual, empat faktor lain dinormalisasi ke 100%). Metrik inilah yang menentukan status MASTERED di atas.
3. Status Label Otomatis:
   - True Mastery < 40%  : "Baru Dipelajari"
   - Recognition tinggi tapi Application rendah : "Tahu Rumus, Belum Terbiasa di Dokkai"
   - True Mastery >= 85% : "Dikuasai Penuh (Mastered)"
   - True Mastery 100%   : "Sempurna (Perfected)"

5. INTEGRASI DENGAN DATABASE SUPABASE & OFFLINE CACHE
================================================================================
Aplikasi dirancang dengan arsitektur Offline-First (Hybrid Resilience):
1. Runtime Cache:
   - Data materi statis (kotoba, kanji, bunpou, sentences) dibaca instan dari
     memori lokal (0 ms network delay, hemat kuota user).
2. Cloud Sync (Supabase):
   - Saat user menyelesaikan soal di QuizEngine atau menulis kanji:
     * Event langsung distream ke tabel PostgreSQL 'user_activity'.
     * Poin mastery per item diakumulasikan ke tabel 'user_mastery'.
   - Saat tombol 'Save to Cloud' diklik atau auto-save aktif:
     * Seluruh progres disinkronkan ke Supabase user metadata dan leaderboard.
3. Keamanan:
   - Seluruh tabel user dilindungi Row Level Security (RLS). User hanya dapat
     membaca dan menulis data progres milik akun UID mereka sendiri.

   - Pencarian dwibahasa, modal kamus detail, kolokasi, dan latihan tulis kata.

2. Jilid II: Kanji (字 - KanjiLibraryView)
   - Akses penuh ke 2.301 karakter kanji.
   - Filter level JLPT (N5〜N1), pencarian karakter, onyomi, kunyomi, arti, radikal.
   - KanjiDetailModal: tabel onyomi/kunyomi dengan audio speaker, kata terkait
     dengan highlight yomikata, serta Writing Studio Canvas (HanziWriter).

3. Jilid III: Tata Bahasa (文 - BunpouLibraryView)
   - Akses penuh ke 915 pola kalimat tata bahasa.
   - Filter level JLPT, filter kategori fungsi semantik (dugaan, syarat, pasif, dll).
   - BunpouDetailModal: rumus formula, tabel aturan sambungan per part of speech,
     catatan nuansa & komparasi pembeda, serta contoh kalimat ber-audio.

4. Jilid IV: Bank Soal JLPT (問 - QuestionLibraryView)
   - Terbagi ke dalam 4 Bagian Standar Ujian Resmi JLPT:
     * 文字・語彙 (Moji & Goi) : Cara baca kanji, kosakata, padanan kata.
     * 文法 (Bunpou)           : Tata bahasa kalimat, susunan kalimat tanda bintang ★.
     * 読解 (Dokkai)           : Wacana bacaan pendek/menengah dengan kotak teks.
     * 聴解 (Choukai)          : Dialog percakapan dengan pemutar audio penutur asli.
   - Uji Mandiri Interaktif: pemain dapat memilih opsi A/B/C/D dengan feedback
     instan benar (hijau) / salah (merah), efek suara, dan akordion pembahasan kunci.

================================================================================
BAGIAN 7: SISTEM BASE EXP & EVENT MULTIPLIER (DINAMIKA REWARD & RPG PROGRESSION)
================================================================================

1. Filosofi Pembagian:
   - "Statistik Profil": Menyimpan frekuensi murni aktivitas belajar pemain
     (berapa kali menulis kanji/kata, berapa kali membuka flashcard, berapa kali quiz).
   - "EXP & Level Karakter": Poin dinamis yang dihitung dari Base EXP entitas
     dikalikan Multiplier kualitas latihan, bertugas menaikkan Level pemain,
     membuka status RPG, dan menghasilkan koin emas (Gold).

2. Rumus Base EXP Entitas:
   a. Kanji / Aksara (getKanjiBaseExp):
      - Bobot Tingkat: Kana/Suuji = 10, N5 = 15, N4 = 25, N3 = 35, N2 = 50, N1 = 70.
      - Bobot Goresan: + (strokeCount * 2).
      - Contoh: Kanji N1 "鬱" (29 goresan) = 70 + (29*2) = 128 Base EXP.
                Kanji N3 "関" (14 goresan) = 35 + (14*2) = 63 Base EXP.

   b. Kosakata (Kotoba) (getKotobaBaseExp):
      - Bobot Tingkat: N5 = 12, N4 = 18, N3 = 28, N2 = 40, N1 = 55.
      - Bobot Panjang Karakter: + (word.length * 2).
      - Bobot Komponen Kanji: + (kanjiCount * 5).
      - Contoh: "関係" (N3, 2 huruf, 2 kanji) = 28 + (2*2) + (2*5) = 42 Base EXP.

   c. Tata Bahasa (Bunpou) (getBunpouBaseExp):
      - Bobot Tingkat: N5 = 20, N4 = 30, N3 = 45, N2 = 65, N1 = 90.
      - Bobot Kompleksitas Rumus: + (subFormulas.length * 5).

3. Rumus Multiplier Event Belajar:
   a. Event Menulis (Kanji & Kotoba Writing Practice):
      - Multiplier Dasar: 1.20x.
      - Bonus Kualitas Menulis:
        * Blind Recall (Tanpa Watermark Panduan) : +0.35x
        * No Hint (Tanpa Animasi Goresan)       : +0.25x
        * Perfect Strokes (0 Kesalahan Goresan)  : +0.25x
        * Fast & Fluent (Waktu 2-8 detik/karakter): +0.10x
      - Penalti:
        * Petunjuk Animasi >2x                  : -0.15x
        * Salah Goresan >3x                     : -0.20x
        * Waktu Menulis >45 detik               : -0.10x
      - Batas Clamp Multiplier: 0.5x s/d 2.5x.

   b. Event Flashcard (Buku Saku & Kotoba):
      - Multiplier Dasar Ringan: 0.35x jika Mastered (Paham Langsung),
        0.175x jika Diulang (Perlu Penguatan).

   c. Event Kuis & Ujian (QuizEngine & Daily Drill):
      - Base EXP per soal: N5=15, N4=20, N3=28, N2=38, N1=50.
      - Multiplier Akurasi Ujian:
        * 100% Akurasi (Sempurna) : 1.30x
        * >= 80% Akurasi          : 1.15x
        * < 50% Akurasi           : 0.85x
      - Bonus Stat INT Karakter: + 0,5% per poin INT (Base * (1 + INT * 0,005)).
